`Программу исполняет процессор а не операционка.


Для того чтобы исполнить программу, её нужно скомпилировать в объектный файл(бинарник) и слинковаться со всеми библиотеками с которыми это требуется. 
Линковка может происходить как и в момент компиляции(статическая линковка), во время старта программы так и в рантайме. Пример:
```C++
#include <stdio.h>

int main() {
	printf("Hello world\n");	
	return 0;
}
```
В хеддере stdio.h находится только объявление функции printf(). При помощи утилиты readelf можно посмотреть, что в скомпилированной программе символ printf unresolved, у него нет реализации и что программа в момент запуска должна слинковаться, c glibc и там найти реализацию.
